# Master Table Conventions

The master table lists every Korean syllable, the main sound values of English letters and letter groups, and every Japanese kana syllable. Each entry has a token ID and a tag. Order: Korean, then English, then Japanese.

## Files

| File | Contents |
|---|---|
| `data/parts/korean.tsv` | Korean entries, generated by `tools/korean.py` |
| `data/parts/english.tsv` | English entries, generated by `tools/english.py` |
| `data/parts/japanese.tsv` | Japanese entries, generated by `tools/japanese.py` |
| `data/master.tsv` | All entries merged and sorted by `Id`, generated by `tools/build_master.py` |
| `data/glossary.tsv` | `IdenticalTo` and `FunctionallyIdenticalTo` for every entry, generated by `tools/build_master.py` |

## Columns

TSV, UTF-8 (NFC), one header row, no quoting, no tabs inside fields.

| Column | Meaning |
|---|---|
| `Id` | Integer token ID (see ID blocks) |
| `Tag` | `Language` + `Romanization` in PascalCase. English adds `_` + `Example`, e.g. `EnglishA_Apple` |
| `Language` | `Korean`, `English` or `Japanese` |
| `Text` | Korean: the syllable (`가`). Japanese: `hiragana/katakana` (`か/カ`), or katakana alone for katakana-only forms. English: the letter or letter group, in lowercase (`a`, `eigh`) |
| `Romanization` | Korean: Revised Romanization, **transliteration mode**, lowercase. Japanese: modified Hepburn, lowercase. English: the same as `Text` |
| `Example` | English only: one example word, lowercase. Empty for the other languages |
| `Phonemic` | Phonemic IPA, without slashes |
| `Phonetic` | Phonetic IPA of the citation form, without brackets. Empty only for silent values |
| `Notes` | Free text, may be empty |

## ID blocks

The gaps in each block leave room to add entries later.

| Language | Range | Assignment |
|---|---|---|
| Korean | 1,000,000 – 1,999,999 | `1000000 + (codepoint − 0xAC00) × 10` |
| English | 2,000,000 – 2,999,999 | Single letters: `2000000 + letterIndex × 10000 + n × 100` (A = 0 … Z = 25; n = 0, 1, 2, … for each sound value). Letter groups: `2500000 + groupIndex × 5000 + n × 100` |
| Japanese | 3,000,000 – 3,999,999 | Sub-blocks: plain gojūon `3000000`, dakuten and handakuten `3100000`, yōon `3200000`, special morae `3300000`, extended katakana `3400000`, obsolete kana `3500000`. Within each sub-block, consecutive entries are spaced 10 apart, in traditional kana order |

Tags must be unique across the whole table.

## IPA conventions (shared by all languages)

- No tie bars, no stress marks, no syllable dots. Affricates are written as two letters: `ts dz tɕ dʑ tʃ dʒ`.
- Use ASCII `g`, not `ɡ` (U+0261).
- Aspiration is `ʰ`. Korean tense consonants use `͈` (U+0348) after the letter: `k͈ t͈ p͈ s͈ t͈ɕ`. Unreleased finals use `̚` (U+031A). Length is `ː`.
- Use `a` for an open central vowel (Korean ㅏ, Japanese あ) and `ɑ` for American *father* / *hot*.

### Korean

- Phonetic values follow the current broadcast standard, for the syllable spoken in isolation.
- Initial consonants:
  - Lax stops and affricates: `k t p tɕ`. Aspirated: `kʰ tʰ pʰ tɕʰ`. Tense: `k͈ t͈ p͈ t͈ɕ`.
  - ㅅ is `sʰ` and ㅆ is `s͈`. Before `i` or `j`, they become `ɕʰ` and `ɕ͈`.
  - ㅎ is `h`, and becomes `ç` before `i` or `j`.
  - ㄹ is `ɾ`. ㅇ is silent.
- Final consonants are neutralized to `k̚ n t̚ l m p̚ ŋ` following 표준발음법, including the rules for consonant clusters.
- Phonemic vowels are one-to-one with the jamo: ㅏa ㅐɛ ㅑja ㅒjɛ ㅓʌ ㅔe ㅕjʌ ㅖje ㅗo ㅘwa ㅙwɛ ㅚø ㅛjo ㅜu ㅝwʌ ㅞwe ㅟwi ㅠju ㅡɯ ㅢɰi ㅣi.
- Phonetic vowels reflect the mergers:
  - ㅐ and ㅔ are both `e`. ㅒ and ㅖ are both `je`.
  - ㅚ, ㅙ and ㅞ are all `we`.
  - ㅢ is `ɰi` after the silent ㅇ, and `i` after any other consonant.
  - After ㅈ, ㅉ or ㅊ, the `j` glide is dropped (져 → `tɕʌ`).
- Phonemic consonants are the underlying jamo, using the same symbols as the phonetic initials, with ㄹ written `l` and ㅅ written `s`. Final clusters are written out in full (값 → `kaps`).

### Japanese

- The standard is Tokyo Japanese. The vowels are `a i ɯ e o`.
- Allophones: し `ɕi`, ち `tɕi`, つ `tsɯ`, ふ `ɸɯ`, ひ `çi`. The r-row is `ɾ`. じ and ぢ are both `dʑi`, and ず and づ are both `dzɯ`.
- Special morae: phonemic `N`, `Q`, `R`. Phonetic citation forms: ん `ɴ`, っ `ʔ`, ー `ː`.

### English

- The standard is General American as spoken by Millennials in San Francisco: the cot–caught merger (`ɑ`), `ɹ`, and the flap `ɾ` in *water*.
- Voiceless stops in a stressed onset are `pʰ tʰ kʰ`.
- Diphthongs are `eɪ oʊ aɪ aʊ ɔɪ`. R-colored vowels are `ɚ ɝ`.

## Glossaries

Both glossaries compare the `Phonetic` column. Entries with an empty `Phonetic` are skipped.

- **`IdenticalTo`:** the tags of all other entries whose `Phonetic` value is exactly the same.
- **`FunctionallyIdenticalTo`:** the tags of all other entries that become equal after the normalization below, excluding entries already listed in `IdenticalTo`. The normalization only merges differences that no Korean contrast depends on.
  1. Remove `̚`, `ː`, the voiceless ring diacritics and the nasalization tilde.
  2. Map: `ɛ→e`, `ɑ→a`, `ɐ→a`, `ɔ→o`, `ɕ→ʃ`, `ʑ→ʒ` (so `tɕ→tʃ`, `dʑ→dʒ`), `ɸ→f`, `ç→h`, `ɴ→ŋ`, `sʰ→s`.
  3. Keep all aspiration (`ʰ`) and tenseness (`͈`) marks on stops and affricates, and keep `ɯ`/`u`, `ɰi`/`wi` and `ɾ`/`ɹ`/`l` apart, because Korean contrasts them.
