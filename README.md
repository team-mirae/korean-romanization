# KRAMS — Korean Romanization to American Millennial Speech

Internal name: `korean-romanization`

KRAMS is a pronunciation-based, yet reversible, romanization system for modern Korean, written for readers who speak American English.

## Objective

- **Pronunciation-based and reversible.** KRAMS spells modern Korean the way it sounds, and the original Hangul must still be recoverable from the romanized text.
- **Target listener.** The target is American Millennial speech as spoken in San Francisco between 2000 and 2026, plus a few widely understood "globalese" elements.
- **Disambiguation by American English pronunciation.** Spellings are read with American English values. For example, `eigh` is read as a flat glide (`ee-iee`) with no `h` sound, which differs from Australian English.
- **Broadcast standard.** Korean pronunciation follows the broadcast standard. American regional, cultural and colloquial variants are left out so that the system stays readable internationally.

## Status

KRAMS is in early design. The specification has not been written yet.
